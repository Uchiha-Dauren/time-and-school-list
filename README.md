# School Timetable & Music Bell 1.1.1

Мектепке арналған пет-жоба: мұғалімдер, пәндер және апталық сағаттар бойынша сабақ кестесін құрады; сабақ уақытында сервер компьютерінің динамигінен MP3/WAV қоңырауын ойнатады.

Қолданылған технологиялар: **Python, FastAPI, SQLAlchemy/SQLite, OR-Tools CP-SAT, APScheduler, pygame, HTML/CSS/JavaScript**. Сыртқы API кілті қажет емес.

## Іске қосу

Python 3.11 немесе жаңарақ нұсқасын қолданыңыз. Архивті ашып, жоба бумасында орындаңыз:

```bash
cd school-timetable-music-bell
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m app.seed --generate
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Windows-та ортаны іске қосу: `.venv\Scripts\activate`. Компьютерде Python `python` деп аталса, бірінші командадағы `python3` орнына соны пайдаланыңыз. Жаңартылған нұсқа macOS-та Python 3.13.2 арқылы тексерілді. `requirements-lock.txt` сол ортадағы нақты тәуелділіктерді сақтайды; дәл сол нұсқалар үшін `pip install -r requirements-lock.txt` қолданыңыз.

- Интерфейс: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- API құжаттамасы: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- Қызмет күйі: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)

Демо **1, 6, 11-сыныптарды, 6 параллельді, 6 мұғалімді, 6 кабинетті және аптасына 96 сабақты** жасайды. Демода A-кластар — қазақша, B-кластар — орысша; бәрі бастапқыда 1-ауысымда. Бұл — қысқа мысал; жүйе 1–11 сыныптардың барлығын қолдайды. Бос базамен бастау үшін `python -m app.seed --generate` командасын өткізіп жіберіңіз.

Демо бар деректердің үстінен жазылмайды. Бірақ `--generate` берілсе, демо қосылмаса да, ағымдағы мектеп деректері бойынша кесте қайта құрылады. Алғашқы іске қосқанда дыбыс пен автоматты қоңыраулар өшірулі. Жобада дайын әндер жоқ.

## Мектепті баптау

1. **Пәндер мен мұғалімдер.** Пәндерді енгізіп, әр мұғалімнің сабақ бере алатын пәндерін белгілеңіз. Бұл — мұғалімнің әкімшілік жазбасы; жеке логин емес.
2. **Мектепте бар сыныптарды тіркеу.** 1–11 сынып деңгейін және мектептің A/B/C сияқты дайын параллельдерін енгізіңіз. Әр класқа атау, сынып деңгейі, оқыту тілі (`kk` — қазақша, `ru` — орысша) және ауысым (**1 немесе 2**) беріледі. Сынып деңгейін қосқанда параллель санын көрсету бірнеше дайын кластың жазбасын бірден тіркеуге көмектеседі; атауларын кейін түзетуге болады.
3. **Апталық сабақ саны.** Жалпы санды сынып деңгейінің оқу жоспарына енгізіңіз. Қажет болса, мұғалімді нақты класқа тағайындағанда `lessons_per_week` арқылы сол класс үшін жеке сан беріңіз. Жеке сан жалпы жоспарды алмастырады; жалпы жоспарда жоқ пәнді де қосуға болады. Бос мән жалпы жоспардағы санды қолданады.
4. **Мұғалім мен кабинет.** Әр қажетті класс/пән жұбына сол пәнді жүргізетін мұғалімді тағайындаңыз. Кабинеттерді тексеру қосулы болса, кабинет те міндетті. Апта бойы осы пәнге бір мұғалім және бір кабинет бекітіледі.
5. **Уақыт.** Мектептің басталу уақытын, сабақтардың ең көп санын, сынып деңгейінің шегін және уақыт белдеуін тексеріңіз. Екі ауысым қажет болса, алдымен баптаулардан қосып, содан кейін кластарға 2-ауысымды беріңіз.
6. **Кестені құру.** Генератор барлық кластарды бірге есептейді. Нәтижені класс, мұғалім және ауысым бойынша қарап, керек сабақты қолмен жылжытыңыз. Қайшылық тудыратын өзгеріс сақталмайды.

Сынып деңгейінің күндік шегі оның соңғы рұқсат етілген сабақ нөмірін де анықтайды. Мысалы, шегі 4 болса, сол ауысымның тек 1–4 сабақтары пайдаланылады. Нақты шек — мектеп пен сынып деңгейі шектерінің кішісі.

Мектеп деректерін, оқу жоспарын, класты, мұғалім тағайындауын немесе сыйымдылықты өзгерткенде ескі кесте мен қоңыраулар тазаланады: қайта генерациялау керек. Тек сағаттар өзгерсе, сақталған сабақтар тексеріліп, қоңырау уақыты қайта есептеледі. Плейлист өзгерісі сабақтарды өзгертпейді.

## Рандом кесте қалай құрылады?

Бағдарлама сабақтарды жай араластырмайды: CP-SAT шешушісі міндетті шарттарға сай нұсқа іздейді.

- Әр класс/пәннің апталық сабақ саны дәл сақталады.
- Бір класс бір мезетте екі сабаққа қатыспайды.
- Бір мұғалім немесе қосулы кабинет бір уақытта екі класқа берілмейді. Екі ауысымда сабақ нөмірі бірдей болуы мүмкін; тексеру **нақты басталу/аяқталу уақытымен** жасалады.
- Тек тағайындалған және сол пәнге тіркелген мұғалім қолданылады.
- Сабақтар дүйсенбі–жұмада, рұқсат етілген сабақ нөмірлерінде өтеді.

Қосымша қалаулар: күрделі пәндерді ертерек қою, пәнді аптаға тарату, күндік жүктемені теңестіру, бос терезелерді азайту. Бұлар міндетті кепілдік емес, оңтайландыру мақсаттары.

Әр генерация жаңа кездейсоқ `seed` таңдап, тең сапалы нұсқалардың ішінен таңдауды өзгертеді. Жауапта қолданылған `seed` қайтарылады. API-ге `{"seed": 42}` беріп, бір бастапқы мәнмен тексеруге болады. **Әр басқанда міндетті түрде басқа кесте шығатынына кепілдік жоқ**: талаптар нұсқаларды шектеуі мүмкін, ал уақыт шегі іздеу нәтижесіне әсер етеді.

| Нәтиже | Мағынасы |
| --- | --- |
| `optimal` | Міндетті шарттар орындалды, мақсат функциясының ең жақсы мәні дәлелденді. |
| `feasible` | Дұрыс кесте табылды, уақыт ішінде ең жақсы екені дәлелденбеді. |
| `invalid` | Дерек жетіспейді немесе қате: мысалы, мұғалім тағайындалмаған. |
| `infeasible` | Қазіргі шектеулермен кесте құру мүмкін емес екені дәлелденді. |
| `timeout` | Уақыт бітті; мүмкін емес деген қорытынды жасалмайды. |

Іздеу әдепкіде 20 секундқа дейін жүреді. Ол жүргенде қоңырау қызметі жалғаса алады. Іздеу кезінде деректер өзгерсе, ескірген нәтиже сақталмайды. Сәтсіз генерация бұрынғы кестені өшірмейді; ал бөлек баптау өзгерісі оны алдын ала тазалауы мүмкін.

## Ауысымдар, үзіліс және музыка

Сабақ **45 минут**, қысқа үзіліс **5 минут**, үлкен үзіліс **15 минут**. Әр ауысымда бір үлкен үзіліс бар: `long_break_after` оның қай сабақтан кейін болатынын көрсетеді, әдепкісі — 2. Таңдалған сабақ күннің соңғы сабағы болса, одан кейінгі үзіліс қолданылмайды.

Мысал: алты сабақ, бірінші ауысым 08:30, екінші ауысым 14:00:

| Сабақ | 1-ауысым | 2-ауысым |
| --- | --- | --- |
| 1 | 08:30–09:15 | 14:00–14:45 |
| 2 | 09:20–10:05 | 14:50–15:35 |
| 3 | 10:20–11:05 | 15:50–16:35 |
| 4 | 11:10–11:55 | 16:40–17:25 |
| 5 | 12:00–12:45 | 17:30–18:15 |
| 6 | 12:50–13:35 | 18:20–19:05 |

Екінші ауысымның толық уақыт торы бірінші ауысыммен қабаттаспайды және түн ортасына жетпейді. **08:30 / 14:00 үшін ең көбі 6 сабақ таңдаңыз.** Бір ауысымның әдепкі шегі — 8; екі ауысымды қосқанда оны өзгерту қажет болуы мүмкін. Әр дайын кластың ауысымын пайдаланушы мектептің жұмыс тәртібіне сай көрсетеді.

Музыканы баптау:

1. Оқылатын `.mp3` немесе `.wav` файлын жүктеңіз: ең көбі **25 MiB**. Жай файл кеңейтімін ауыстыру жеткіліксіз — контейнер тексеріледі.
2. Сабақтың басы/соңы, қысқа/үлкен үзіліс, күннің соңы оқиғаларына плейлист таңдаңыз.
3. Ойнату ұзақтығын (1–120 секунд) және дыбыстың біртіндеп өшуін (0–30 секунд, жалпы уақыттан аспайды) беріңіз. Әдепкісі — 15 секунд, оның соңғы 2 секунды өшуге кетеді.
4. Алдымен дыбыс өшірулі кезде сынаңыз. Нақты колонканы тексеру үшін дыбысты қосып, баптауды сақтап, тест ойнатуды басыңыз.
5. Уақыт белдеуі мен кестені тексерген соң автоматты қоңырауды қосыңыз.

**Дыбыс браузерден емес, Python сервері тұрған компьютерден шығады.** Колонка сол компьютерге қосылуы, компьютер қосулы және ұйқы режимінде болмауы керек. `Stop` ағымдағы әнді тоқтатады; келесі автоматты қоңырауды тоқтату үшін жоспарлағышты баптаулардан өшіріңіз.

Қоңыраулар тек сақталған кестеде сабақ бар уақыттарға жасалады. Бірнеше класс бір уақытта оқыса, мектепке ортақ бір оқиға жиыны қолданылады. `end_of_day` — екі ауысымның сол күнгі ең соңғы сабағының аяқталуы.

Бір мезеттегі оқиғалар үшін бір ғана ән ойналады. Басымдық: **күн соңы → үлкен үзіліс → қысқа үзіліс → сабақ соңы → сабақ басы**. Сол мезетте бар оқиғаның плейлисті бос болса, келесі басымдық қаралады. Әндер ретімен ауысады, кезек қайта іске қосылғанда сақталады; плейлистті сақтау кезекті басына қайтарады.

Жоспарлағыш мектеп уақыт белдеуін (`Asia/Almaty`) қолданады, демалыс күндері үндемейді. Үш секундтан артық кешіккен қоңыраулар кейін ойнатылмайды. Қайта қосқанда бір қоңырау қайталанбас үшін ойнату талпынысы базаға алдын ала тіркеледі. Компьютер осы аралықта өшсе немесе аудио құрылғы істемесе, сол қоңырау өткізіліп кетуі мүмкін.

## Негізгі API

Толық схема `/docs` бетінде. Белгісіз JSON өрістері қабылданбайды; апта күндері `0=дүйсенбі` ... `4=жұма`.

| Сұрау | Мақсаты |
| --- | --- |
| `GET /api/catalog` | Мектеп деректері және баптаулар. |
| `POST /api/subjects`, `POST /api/teachers`, `PUT /api/teachers/{id}` | Пәндер және мұғалімдердің біліктілік пәндері. |
| `POST /api/grades`, `PUT /api/grades/{id}` | Сынып деңгейі, параллель саны, сабақ шегі. |
| `POST /api/classes`, `PUT /api/classes/{id}` | Дайын кластың атауы, деңгейі, тілі және ауысымы. |
| `POST /api/rooms` | Кабинет қосу. |
| `POST /api/curriculum` | Сынып деңгейіне ортақ апталық пән саны. |
| `POST /api/assignments` | Класс/пәнге мұғалім, кабинет және жеке апталық сан. |
| `POST /api/seed` | Бос мектепке демо жүктеу. |
| `PUT /api/settings` | Толық баптау объектісін ауыстыру. |
| `POST /api/timetable/generate` | Кесте құру; міндетті емес JSON: `{"seed":42}`. |
| `GET /api/timetable` | Сабақтар; `class_id`, `teacher_id` сүзгілері; `shift_periods` уақыт торлары. |
| `PATCH /api/timetable/{id}` | Сабақты `weekday`, `period` арқылы жылжыту. |
| `GET /api/bells` | Қоңырау оқиғалары, `shift_periods`, басымдықтар. |
| `GET /api/music`, `POST /api/music/upload` | Әндер және multipart `file` жүктеуі. |
| `PUT /api/music/playlists/{event_type}` | Ретімен `track_ids` сақтау; бос тізім плейлистті тазартады. |
| `POST /api/music/test`, `POST /api/music/stop` | `track_id` сынау немесе ойнатуды тоқтату. |
| `GET /api/music/status` | Аудио қатесі және жоспарлағыш күйі. |

`PUT /api/settings` ішінара жаңарту емес: `catalog.settings` мәнін алып, қажетті өрістерін өзгертіп, түгел жіберіңіз. Берілмеген өрістер әдепкі мәнге қайтады.

## Тексеру, файлдар және шектеулер

```bash
source .venv/bin/activate
python -m pytest -q
```

Тесттер нақты колонканы ойнатпайды: есептеу, API, музыка ұзақтығы, тоқтату және жоспарлағыш жасанды құрылғылармен тексеріледі.

- `app/services/timetable.py` — генератор және тәуелсіз тексеруші.
- `app/services/bells.py` — ауысым уақыттары және қоңыраулар.
- `app/services/audio.py`, `app/scheduler/runner.py` — жергілікті дыбыс пен жоспарлағыш.
- `app/models`, `app/schemas.py`, `app/routers` — база, енгізу тексерулері, API.
- `app/migrations.py` — бастапқы архивтің SQLite схемасын жаңарту.
- `app/templates`, `app/static` — браузер интерфейсі.

Деректер әдепкіде `data/` ішінде: `school.db` және `music/`. Басқа орынды `SCHOOL_DATA_DIR` арқылы беруге болады. Сақтық көшірме үшін серверді тоқтатып, деректер бумасын толық көшіріңіз. Бастапқы нұсқаның базасы жаңартылғанда бар кластарға `kk` және 1-ауысым мәндері беріледі: оларды нақты мектепке қарай түзетіңіз.

Бұл — **бір жергілікті әкімші интерфейсі, бір сервер процесі және бір аудио құрылғы** үшін жасалған жоба. Нақты қоңыраумен `--workers 1` қолданыңыз, `--reload` қоспаңыз.

Мұғалімдердің жеке логині, рөлдер, тілдік біліктілікті тексеру, мұғалімнің бос емес уақыттары, мереке күнтізбесі, кабинетті автоматты таңдау және үздіксіз жеткізу кепілдігі әзірге жоқ. `kk/ru` кластың оқыту тілін белгілейді; мұғалімнің сол тілде сабақ бере алатынын адам тексереді. Интерфейс пен диагностиканың бір бөлігі ағылшын тілінде. Желілік қолдануға шығарудан бұрын тіркелу/рұқсат жүйесін және орналастыру тәсілін қосу қажет.
